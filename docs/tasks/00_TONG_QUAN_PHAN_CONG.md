## 2. Quy chuẩn đặt tên Issue & Sub-issue

Mọi task khi tạo trên GitHub bắt buộc theo cấu trúc:
* **Issue Cha (Parent Issue):** `[Phase X][Tên Module] Tên công việc tổng quát`
  * *Ví dụ:* `[Phase 2][Reading] Module Luyện thi Reading toàn diện`
* **Issue Con (Sub-issue):** `[Phase X][Tên Module][Sub-issue X] Tên công việc cụ thể`
  * *Ví dụ:* `[Phase 2][Reading][Sub-issue A] Giao diện Reading Split-view & Timer`
